# 🏆 LPL 赛事中心 —— LPL 赛程查询

一个零依赖的本地 Web 应用，实时获取 **LPL（英雄联盟职业联赛）** 的赛程、比分、积分榜和比赛详情（选手 / 英雄 / 出装 / Ban 位）。

![Node](https://img.shields.io/badge/Node.js-%3E%3D18-339933) ![License](https://img.shields.io/badge/license-MIT-blue)

---

## ✨ 功能

- **赛程浏览**：日期条快速切换（±3 天）、日期选择器、状态筛选（全部 / 未开始 / 进行中 / 已结束）；今天无比赛时自动跳到最近比赛日
- **按战队筛选**：跨全部日期展示所选战队的全部比赛，可与状态筛选叠加
- **对阵图**：2026 赛季三赛段结构总览——第一/二/三赛段的分组（登峰组 / 坚韧组 / 涅槃组等）、骑士之路、淘汰赛逐轮对阵（含比分与胜者高亮），当前赛段卡片高亮并内嵌当前赛段积分榜
- **完整比分**：已结束比赛显示系列赛比分与胜者，进行中比赛实时高亮
- **真实队徽**：腾讯官方队徽（`img.crawler.qq.com`），加载失败自动回退为文字徽标
- **积分榜**：按赛段筛选（第三赛段 / 第二赛段 / 第一赛段 / 整个赛季），**按组别分别展示**（登峰组 / 坚韧组 / 涅槃组等），组内按**积分**排序（积分 = 系列赛胜场 × 3），含 排名 / 场次 / 积分 / 胜 / 负 / 胜率 / 净胜场 / 近 5 场 / 连胜连败
- **比赛详情**（点击任意比赛卡片）：
  - 逐局选手名单、中文分路（上单/打野/中单/下路/辅助）
  - **英雄头像图标**（悬停看中文英雄名，Riot Data Dragon 图标源）
  - **真实装备图标**（腾讯官方 CDN；不足 6 格自动补占位，悬停看装备名）
  - 团队数据：击杀 / 推塔 / 小龙 / 大龙 / 金币
  - **Ban 位英雄图标**（带半透明斜线标记）
- **自动刷新**：有直播或临近比赛时每分钟静默刷新；顶部按钮可强制刷新
- **本地化时间**：所有时间自动转为你的本地时区
- **磁盘缓存**：赛程/结构/积分榜/详情自动落盘到 `data/cache.json`（节流写入），**服务重启不丢数据**；上游接口暂不可用时自动用最近一次缓存兜底，断网也能看
- **智能刷新**：缓存时长按比赛状态动态调整——**有比赛进行/临近开赛时 60 秒刷新**（比分实时），**无比赛时缓存 1 小时**（已结束数据不变，基本不重复拉取）；详情缓存 15 分钟

## 🚀 快速开始

**方式一：双击启动脚本（推荐）**

双击项目目录下的 **`启动.bat`**，会自动检查 Node.js、启动服务并打开浏览器。

**方式二：命令行**

```bash
cd lol-schedule
node server.js
```

打开浏览器访问：**http://127.0.0.1:45231**

> - 需要 Node.js ≥ 18（自带 `fetch`，无任何第三方依赖，无需 `npm install`）。
> - 默认端口 **45231**（不常用端口，避免冲突）；自定义端口：`PORT=9090 node server.js`。
> - 若启动脚本提示"服务已在运行"，说明已有一个实例在跑，直接访问即可。

## 📡 数据来源

| 数据 | 来源 |
|------|------|
| 赛程 / 比分 / 战队 | 腾讯官方赛事接口（`apps.game.qq.com`） |
| 比赛详情（选手/英雄/出装/Ban） | 腾讯 `open.tjstats.com` |
| 英雄头像图标 | Riot Data Dragon（`ddragon.leagueoflegends.com`） |
| 装备图标 | 腾讯官方 CDN（`game.gtimg.cn/images/lol/act/img/item/`） |
| 队徽 | 腾讯官方战队列表文件（`lpl.qq.com/web201612/data/LOL_MATCH2_TEAM_LIST.js`） |

默认展示当前赛季（2026 职业联赛）全部阶段赛程。

## 🔌 API

| 接口 | 说明 |
|------|------|
| `GET /api/lpl/schedule` | LPL 当前赛季全部赛程（`?force=1` 强制刷新） |
| `GET /api/lpl/seasons` | LPL 赛季列表 |
| `GET /api/lpl/season` | 赛季结构（三赛段分组 / 骑士之路 / 淘汰赛对阵 / 各赛段积分榜） |
| `GET /api/lpl/match/:id` | LPL 单场比赛详情（已结束） |
| `GET /api/standings?league=lpl&stage=第三赛段` | 积分榜（可按赛段筛选：全部/第一赛段/第二赛段/第三赛段） |

## 📁 项目结构

```
lol-schedule/
├── server.js            # HTTP 服务：静态资源 + API + 内存/磁盘缓存
├── lib/
│   ├── lpl.js           # LPL 数据（腾讯官方接口）
│   ├── standings.js     # 积分榜计算
│   └── names.js         # 队伍短名 / 配色
├── public/              # 前端（原生 HTML/CSS/JS，无构建）
│   ├── index.html
│   ├── style.css
│   └── app.js
├── data/cache.json      # 磁盘缓存（自动生成，重启不丢）
└── README.md
```

## ⚠️ 已知限制

- LPL 比赛详情仅在比赛结束后由腾讯生成，未开赛的比赛详情返回「暂无数据」。
- 腾讯接口未提供选手级 KDA（出装/英雄/Ban 均有）。
- 数据源接口可能偶发变慢或更新，已内置缓存与静默重试。
